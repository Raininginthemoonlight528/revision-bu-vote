# revision-bu-vote

Petit site de vote girly/cute pour choisir entre :
- BU saint charles
- BU luminy

## Lien du site

Une fois publié via GitHub Pages, le site sera accessible ici :
https://raininginthemoonlight528.github.io/revision-bu-vote/

## Fonctionnement

- 9 votes au total
- le résultat final s’affiche automatiquement quand tout le monde a voté
- design pastel, girly et cute
- bouton pour réinitialiser les votes pour tester le sondage

## Fichiers du site

- `index.html`
- `style.css`
- `script.js`

## Pour publier le site sur GitHub Pages

1. Ouvre le repo GitHub
2. Va dans Settings > Pages
3. Source : Deploy from a branch
4. Sélectionne la branche `main` et le dossier `/root`
5. Enregistre

La page sera alors disponible sur l’URL ci-dessus.
